# ATM Management System

A simple command-line based ATM Management System developed using Python and Object-Oriented Programming (OOP) concepts.

## Features
- Create ATM PIN
- Change Existing PIN
- Check Account Balance
- Secure PIN Verification
- Menu-Driven Interface

## Technologies Used
- Python
- OOP (Classes & Objects)
- Loops
- Conditional Statements
- User Input Handling

## Project Description
This project simulates basic ATM operations through a console-based application. Users can create a PIN, update the PIN, and securely check account balance. The project demonstrates the implementation of real-world banking workflow logic using Python.

## How to Run
1. Install Python
2. Save the file as `atm.py`
3. Open terminal in project folder
4. Run the command:

```bash
python atm.py
